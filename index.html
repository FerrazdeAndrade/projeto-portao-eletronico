📈 O que é um Gauge e suas Funcionalidades

O que é: O Gauge (ou medidor gráfico) é um componente visual utilizado em dashboards para exibir métricas consolidadas de forma rápida, intuitiva e proporcional, facilitando a interpretação imediata do estado de operação.

Funcionalidades do Gauge:

  • Monitoramento Proporcional: Converte o volume de acionamentos (aberturas e fechamentos) em uma distribuição visual clara.
  • Feedback Dinâmico: Permite alteração automática de cores conforme limiares de uso pré-estabelecidos.
  • Persistência de Dados: Atualiza-se instantaneamente a cada evento registrado no sistema ou banco de dados.

Funções para Informação:

  • Sintetizar grandes volumes de dados operacionais em um único indicador central.
  • Agilizar a tomada de decisão e análise rápida do fluxo de tráfego/operações do portão.
  • Oferecer suporte visual executivo integrado aos relatórios de auditoria e requisitos do sistema.

⚙️ Estados de Funcionamento do Portão

1. Estado ABRINDO (Comando: ▲ ABRIR):

  • Portão: Recolhe gradualmente do chão até o topo (animação CSS de 3 segundos).
  • Sinalizador: LED Verde pisca no topo da garagem a cada 250ms.
  • Sonoro: Bipes contínuos soam via áudio do navegador (Web Audio API).
  • Resultado: Ao chegar no topo, o som para, o LED permanece Verde Aceso (Fixo) e o portão fica parado no topo aguardando nova ordem.

2. Estado FECHANDO (Comando: ▼ FECHAR):

  • Portão: Desce gradualmente do topo até fechar completamente a entrada.
  • Sinalizador: LED Vermelho pisca no topo da garagem.
  • Sonoro: Bipes de alerta de fechamento.
  • Resultado: Ao fechar, o som para, o LED permanece Vermelho Aceso (Fixo) e o portão fica parado e fechado.

📑 Resumo do Projeto

O Projeto Portão Automático é um sistema de automação residencial desenvolvido para controlar a abertura e o fechamento de um portão de garagem. A solução conecta uma interface gráfica web (HTML, CSS, JS e Python/Flask) a um circuito microcontrolado Arduino Uno R3, garantindo persistência dos dados de acionamento em banco de dados SQLite.

📋 Requisitos do Sistema

Requisitos Funcionais: Definem as funcionalidades ativas do sistema, como a capacidade de receber comandos de abertura e fechamento via controle remoto IR ou interface web, acionar o servomotor SG90 nos ângulos programados, registrar histórico de eventos no banco de dados SQLite e sinalizar o status em tempo real por LEDs e Buzzer.

Requisitos Não Funcionais: Determinam a qualidade e desempenho da aplicação, como o tempo de resposta da animação na interface (máximo de 3 segundos), usabilidade e responsividade do layout CSS, confiabilidade na transmissão de dados via porta Serial a 9600 bps e geração de áudio no navegador via Web Audio API.

RF01 - Controle do Servo: Movimentação angular precisa de 0° a 120°.

RF02 - Receptor IR: Leitura de frequência infravermelha para controle remoto físico.

RF03 - Auditoria de BD: Incremento automático do contador a cada acionamento gravado no SQLite.

RNF01 - Usabilidade: Layout gráfico proporcional expandido para visualização clara da garagem.

🤖 ARDUINO E SUAS FUNÇÕES

Servo Motor SG90: Atua como o mecanismo mecânico de elevação do portão.

LEDs e Buzzer Sonoro: Sinalizadores de alerta visual e sonoro durante a movimentação.

Sensor Infravermelho (IR): Recepção dos sinais sem fio enviados pelo controle remoto portátil.

#include <Servo.h>
#include <IRremote.h>

const int RECV_PIN     = 2;
const int LED_VERMELHO = 4;
const int LED_VERDE    = 5;
const int SERVO_PIN    = 9;
const int PIEZO_BUZZER = 10;

const uint16_t COMANDO_BOTAO = 0x44;
int estadoPortao = 0;

Servo meuServo;

void emitirBip(int duracao) {
  for (int i = 0; i < (duracao * 2); i++) {
    digitalWrite(PIEZO_BUZZER, HIGH);
    delayMicroseconds(300);
    digitalWrite(PIEZO_BUZZER, LOW);
    delayMicroseconds(300);
  }
}

void setup() {
  Serial.begin(9600);
  delay(500);

  pinMode(LED_VERMELHO, OUTPUT);
  pinMode(LED_VERDE, OUTPUT);
  pinMode(PIEZO_BUZZER, OUTPUT);

  meuServo.attach(SERVO_PIN);
  meuServo.write(0);

  estadoPortao = 0;
  digitalWrite(LED_VERMELHO, HIGH);
  digitalWrite(LED_VERDE, LOW);
  digitalWrite(PIEZO_BUZZER, LOW);
  delay(500);

  IrReceiver.begin(RECV_PIN, ENABLE_LED_FEEDBACK);
  Serial.println("Sistema de portao automatico iniciado!");
}

void loop() {
  if (IrReceiver.decode()) {
    uint16_t comando = IrReceiver.decodedIRData.command;

    if (comando == COMANDO_BOTAO) {
      if (estadoPortao == 0) {
        emitirBip(200);
        for (int angulo = 0; angulo <= 120; angulo += 10) {
          meuServo.write(angulo);
          digitalWrite(LED_VERDE, HIGH);
          digitalWrite(LED_VERMELHO, LOW);
          delay(80);
        }
        emitirBip(400);
        estadoPortao = 1;
        Serial.println("Estado do Portao: ABERTO");
      } 
      else if (estadoPortao == 1) {
        for (int angulo = 120; angulo >= 0; angulo -= 10) {
          meuServo.write(angulo);
          digitalWrite(LED_VERMELHO, HIGH);
          digitalWrite(LED_VERDE, LOW);
          delay(80);
        }
        emitirBip(150);
        delay(150);
        emitirBip(150);
        estadoPortao = 0;
        Serial.println("Estado do Portao: FECHADO");
      }
    } 
    else if (comando != 0 && comando != 0xFFFF) {
      Serial.print("Outro botao ignorado: 0x");
      Serial.println(comando, HEX);
    }
    IrReceiver.resume();
  }

  if (Serial.available() > 0) {
    char comandoSerial = Serial.read();
    
    if (comandoSerial == 'A' && estadoPortao == 0) {
      emitirBip(200);
      for (int angulo = 0; angulo <= 120; angulo += 10) {
        meuServo.write(angulo);
        digitalWrite(LED_VERDE, HIGH);
        digitalWrite(LED_VERMELHO, LOW);
        delay(80);
      }
      emitirBip(400);
      estadoPortao = 1;
      Serial.println("Estado do Portao: ABERTO");
    } 
    else if (comandoSerial == 'F' && estadoPortao == 1) {
      for (int angulo = 120; angulo >= 0; angulo -= 10) {
        meuServo.write(angulo);
        digitalWrite(LED_VERMELHO, HIGH);
        digitalWrite(LED_VERDE, LOW);
        delay(80);
      }
      emitirBip(150);
      delay(150);
      emitirBip(150);
      estadoPortao = 0;
      Serial.println("Estado do Portao: FECHADO");
    }
  }
}
